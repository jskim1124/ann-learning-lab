# 특징 그래프·추론 내보내기 검토

## 이번 변경

- 연습은 그래프가 기본 작업면이다. 모든 뉴런 기준선·방향 화살표와 최종 경계를 함께 표시하고 각각 끌 수 있다. 자료 점은 축을 바꾸지 않는 동안 고정된다.
- 승부차기의 자유 탐침을 제거했다. 실제 점을 선택했을 때만 그 사례의 예측과 연결 지도가 표시된다. 숫자·텍스트·그림 모두 같은 원칙을 사용한다.
- 그림의 직접 계산, 두 특징의 분포 비교와 사용자 화소 곱셈표, 뉴런의 합이 0인 선, 한 사례를 30번 학습한 선의 움직임을 각 확인 문제와 연결했다. 숫자·텍스트도 같은 네 단계 구조다.
- 텍스트는 통계 특징 분류이며 의미 이해가 아님을 명시한다. OMR의 ‘열 번호 × 진하기 합’은 무게중심이 아니다. 표시 숫자는 반올림값임을 밝힌다.

## 수학적 검토

원래 특징 곱셈표를 직교화해서 다른 특징으로 바꾸지 않는다. 비직교 특징에는 Gram 행렬의 역행렬로 이중 기저를 구한다. 학습 연결값을 선택한 특징의 span에 제한하므로 실제 자료와 같은 좌표를 갖는 재구성 입력의 예측이 일치한다. 이 조건에서만 2차원 경계를 제공한다. 그림 전체 학습에서는 특징 분포만 그리며 가짜 경계를 제공하지 않는다.

흰/색 배경의 농도는 예측 점수이며 실제 정확도의 보장이 아니다. 뉴런을 배우는 장면에서는 단일 뉴런의 변환 전 합의 부호와 크기를 그린다. 최종 경계는 1등 클래스끼리의 점수차를 보간한 근사 선이다. 2등끼리 같아지는 곳에는 경계를 그리지 않는다.

대표선의 시작 모델은 원리를 보기 위한 의도적인 예제다. 이후 30프레임은 실제 역전파 결과이며 원하는 방향으로 선을 임의 이동시킨 애니메이션이 아니다. 한 사례를 반복한 장면과 모든 자료를 한 바퀴씩 보는 연습 단계를 구별한다. 한 선이 언제나 같은 방향으로 움직인다고 설명하지 않는다.

## 내보내기

새 TurboWarp 확장은 파라미터·클래스 이름·전처리만 포함한다. 학습 예시, 재학습 블록, 외부 서버 전송은 없다. 감지 이벤트, 라벨, 클래스별 점수, 임곗값을 제공한다. 웹캠은 사용자 실행 시 켜지며 중지 시 트랙을 종료한다. 숫자·텍스트의 원래 값도 학습 때의 축·범위로 변환한다.

공식 Scratch는 임의 JavaScript 확장을 지원하지 않으므로 카메라 확장은 TurboWarp용이라고 명시한다. 별도 `.sb3`는 표준 Scratch 블록으로 추론하며 입력 목록을 채워 사용한다. 내보낸 파일이 학습 자료를 숨기는 보안 장치라는 주장은 하지 않는다.

## 검증 범위와 한계

- 특징 계산, 비직교 축의 좌표 왕복, 좌표별 모델 예측 일치, 단일선 실제 갱신, 다중 클래스 경계, 세 활성화 함수의 내보낸 라벨·점수 일치, 숫자·텍스트 전처리, 네 단계 화면 진행·퀴즈·복귀를 자동 검증했다.
- 브라우저에서 OMR의 네 단계 → 100회 학습 → 서로 다른 점 클릭, 숫자 탐구 → 100회 학습 → 점 클릭, 텍스트 즉시 특징 계산을 확인했다. 브라우저 오류 로그는 없었다.
- 1280×720, 1280×800, 768×1024, 390×844에서 새 작업면의 배치를 확인했다. 작은 화면은 한 작업면씩 전환한다. 720px 높이에서 완료 피드백이 다음 버튼을 아래 메뉴 뒤로 밀던 문제는 예측 선택지를 완료 후 접어 해결했다. 수정 후 패널의 실제 높이와 내용 높이가 모두 556px이고 다음 버튼의 hit target이 버튼 자체임을 확인했다.
- 실제 개인 웹캠 권한을 열거나 외부 TurboWarp 에디터에 확장 파일을 설치하지 않았다. 생성된 확장 실행은 VM 단위 테스트로 검증했다. 실제 다양한 손 모양·배경의 인식 성능을 보장하지 않는다.
