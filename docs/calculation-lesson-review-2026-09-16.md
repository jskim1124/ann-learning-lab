# 계산 설명·연습 흐름 보완 검토

## 수업 내용

- 4×4 작은 그림에서 흰색 0, 회색 0.5, 검정 1을 확인한다. 각 칸의 진하기에 특징 곱셈표를 적용하고, 0이 아닌 다섯 항을 순서대로 더한다. 자동 재생·한 단계 진행·다시 보기를 제공한다.
- 작은 예제는 실제 학습 자료와 분리한다. 실제 자료 탭에서는 196칸의 계산, 자료 평균, 가장 먼 거리, 좌표 변환을 순서대로 보여 준다. 표시값은 반올림이다. 자동 특징/사용자 특징에는 작은 예제가 동일하다고 주장하지 않는다.
- 특징 곱셈표와 학습되는 뉴런 연결값을 구분한다. 가운데 진하기와 위치 가중합은 사람이 정한 특징이다. 자동 특징은 정답을 사용하지 않는다.
- 두 뉴런 예제는 입력 × 연결값 + 더해주는 값 → 부드럽게 줄인 신호 → 출력별 가중합 순서다. 검은 경계는 가장 큰 두 출력값이 같아지는 곳이다. 은닉 뉴런 하나의 기준선과 동일하지 않다.
- 선 움직임의 작은 예제는 다른 연결값을 고정하고 더해주는 값의 세 후보(−0.1, 0, +0.1)를 비교하는 제한된 실험이다. 실제 자료 탭은 오차에 따른 역전파 30회 갱신이다. 제한된 실험을 실제 학습 알고리즘과 같은 것으로 설명하지 않는다.
- 퀴즈는 선택형이며 정답/오답 색과 텍스트를 함께 제공한다. 단계 목차로 앞 내용을 다시 볼 수 있다.
- 승부차기 2뉴런 장면의 배경·검은 경계도 예제 신경망의 실제 출력으로 계산한다. 규칙 설명용 띠를 실제 출력인 것처럼 그리지 않는다.

## 연습과 입력

- 그림·숫자·텍스트 모두 연습 안에서 축을 선택한다. 축 변경은 분포와 축 이름을 갱신하고 학습을 초기화한다. 다른 페이지로 이동하지 않는다.
- 목차의 3번 이름은 항상 이해다. 자율 활동은 이해를 비활성화하고 자료에서 연습으로 바로 간다. 연습의 뒤로 가기는 자료 화면이다.
- 점을 고르기 전에도 네트워크 구조를 표시한다. 숨은 뉴런을 16개로 늘려도 모두 표시하고 그래프와 같은 색을 사용한다. 값은 점을 골랐을 때 표시한다.
- 경계의 표본 해상도와 선 연결을 개선했다. 진짜 직선/구간별 직선을 임의 곡선으로 바꾸지 않는다. 전체 픽셀 모델은 2차원 지도의 배경을 실제 전체 모델의 경계라고 표시하지 않는다.
- 드로잉 붓을 검정, 숫자/자율 24px·OMR 28px로 조정했다. 미리보기와 학습 입력 사이에 별도 밝기 보정은 넣지 않았다.
- 숫자 자료의 사례 이름 입력을 제거하고 자동 이름을 사용한다. XLSX 첫 시트에서 클래스와 숫자 특징을 읽는다. 기존 자료 교체는 확인 후 적용하며 파일을 서버로 전송하지 않는다. 최대 2MB·1,000행·특징 2~5개·클래스 2~6개다. 빈 숫자/날짜/중복 열 이름/잘못된 파일은 거부한다.

## 검증

- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 27개 테스트 파일, 116개 테스트 통과. 계산값, 방향 비교, 실제 XOR 예제, 16개 뉴런 표시, 진한 붓과 픽셀 동일성, 페이지 복귀, 엑셀 검증·실제 OOXML 파일 파싱, 기존 학습·내보내기 회귀 포함.
- 실제 브라우저에서 숫자 네 단계와 선택형 피드백 → 연습, 특징 변경, 뉴런 16개, 점 선택, 10회 학습, 이해로 되돌아간 후 연습 복귀를 확인했다.
- OMR 작은 예제의 위치 가중합 11을 확인했다. 합성 XLSX를 브라우저 업로드해 4개 자료·2개 클래스·2개 특징 생성 후 이해 없이 연습에 진입했다. 브라우저 오류 로그는 없었다.
- 1280×720 및 768×1024에서 확인했다. 세로 화면은 학습/모델 패널을 전환하며 문서 크기는 화면 크기와 같았다. 사용자 화면 크기·확대율 전체를 보장하는 검증은 아니다.
- 개인 웹캠 하드웨어나 외부 Scratch/TurboWarp 에디터는 이번 변경에서 다시 열지 않았다. 관련 기존 자동 테스트는 통과했다.
