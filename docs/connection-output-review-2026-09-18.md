# 연결값과 출력 수업의 논리 검토

대상: `neuronIntroduction`, `outputLesson`, 공통 그래프, 작은 예제의 실제 신경망 계산. 수업 효과를 학생에게 실험해 입증한 결과는 아니며, 설명·수식·화면의 일치 여부를 검토했다.

## 수정한 오개념 위험

| 혼동할 수 있는 설명 | 수정·검증 |
| --- | --- |
| 픽셀의 1·0.5와 연결값의 1·0.5가 같은 뜻이다 | 픽셀은 흰색 0·검정 1로 정한 진하기 눈금. 작은 예제의 중간 회색은 (0+1)÷2=0.5. 연결값은 입력을 얼마나 반영할지 정한 곱하는 수로 별도 설명. |
| 1·0.5가 그림에서 자동으로 나온 값이다 | 예제 제작자가 정한 연결값이며 학습 결과가 아님을 명시. 같은 입력 0.2를 그대로/절반 반영하는 곱셈을 비교. 실제 앱 초기화는 임의 연결값, 학습은 오차에 따른 갱신이다. |
| 연결값 1이 0.5보다 항상 좋거나 중요하다 | 좋고 나쁨의 순위가 아니라고 명시. 같은 좌표·같은 다른 연결값에서 입력 변화가 합에 반영되는 크기만 비교했다. |
| 은닉 뉴런 자체가 정답을 나누는 선이다 | 은닉 뉴런은 곱셈·덧셈·값 변환을 하는 계산기이고, 색 선은 그 합이 0인 자리다. 클래스 정답선이라고 부르지 않는다. |
| 모든 뉴런은 음수를 0으로 만든다 | 원리 예제의 ReLU 동작으로 한정. 실제 학습 코드에는 tanh/sigmoid/ReLU 선택이 있으며 서로 다르다. |
| 검은 경계가 곧 실제 정답이다 | 모델의 현재 1등 출력이 바뀌는 경계라고 명시. 정답 B인 고정 예제에서 처음 모델은 A를 예상한다. 정답 표와 예상을 동시에 표시한다. |
| 새 좌표에도 모델이 실제 정답을 알려 준다 | 미리 정한 가상 예제에만 독립적인 정답 표를 붙임. 자유 좌표는 ‘정답 미지정’으로 표시. 모델 예상으로 정답을 만들지 않는다. |
| 선을 숨겼어도 배경으로 답이 보인다 | 숨김 상태에서는 기준선·화살표·출력 경계·영역 배경을 모두 숨김. 직접 그린 획과 정확히 만난 자리만 피드백으로 채움. |
| 두 출력의 점수가 같으면 언제나 최종 경계다 | A/B 두 클래스 장면에서만 동점 경계를 설명. 세 클래스에서는 최고 점수끼리의 경계만 그리는 기존 `classContours`를 사용. A=B=0.5, C=0.55이면 C 영역이라는 테스트 추가. |
| C를 추가하면 기존 A·B 점수도 바뀐다 | 기존 점수 계산을 그대로 두고 C 계산을 추가. 다만 확률로 정규화하면 전체 합이 달라져 기존 확률은 달라진다. |
| 은닉 뉴런 수가 출력 수를 정하거나 많으면 항상 잘 맞힌다 | 이 다중 분류 모델은 클래스별 출력 하나를 사용한다고 한정. 은닉 1개/2개 모두 출력 3개를 유지하며 성능 보장은 하지 않는다. |
| 점수 0.7은 70%, 예상 80%는 정답률 80%다 | 출력 점수와 확률, 여러 자료에서 맞힌 비율을 구분. softmax는 선택해서 여는 별도 설명으로 분리하고 실제 계산과 일치시켰다. |
| 두 점수가 화면에서 같아 보이는데 한 클래스만 예상한다 | 출력 좌표 탐색은 0.01 간격으로 맞추고 점수는 소수 셋째 자리까지 표시. (0.36, 0.27)의 신호 0.495, A=0.505, B=0.495를 그대로 계산할 수 있다. 실제 동점은 따로 표시. |

## 단계별 계산

작은 예제는 학습 데이터나 모델 훈련 결과가 아니다. 앞의 슬라이더 실험 뒤에는 처음의 연결값을 다시 사용한다고 알린다.

1. 입력 (0.2, 0.2) → 0.2×1 + 0.2×0.5 + 0 = 0.3.
2. A: 0.3×(−1) = −0.3. 다음 장면에서 −0.3 + 1 = 0.7.
3. B: 0.3×1 + 0 = 0.3.
4. 직접 계산: 가로만 0.3으로 바꾸면 신호 0.4, A 점수 0.6. 객관식 정답은 실제 forward 계산과 대조.
5. 더 큰 출력으로 예상 답을 선택. 좌표 탐색과 선 공개를 여기서 허용.
6. C 추가: 같은 신호 0.3×0.5 + 0.3 = 0.45. 새 연결값의 출처도 예제 설정이라고 알림.
7. 은닉 뉴런 추가: 세로를 보내는 두 번째 신호가 C에만 더해지는 단순 예제로 관계 확인. 실제 학습 모델은 이 예제 연결값으로 교체하지 않음.
