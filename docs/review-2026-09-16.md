# 이미지 학습 구조 및 교육 내용 검토

## 발견한 문제와 수정

| 항목 | 검토 결과와 조치 |
|---|---|
| 웹캠 입력 | 손을 사람이 정한 다섯 수치로 바꾸던 경로를 제거. 실제 사진의 중앙 정사각형을 14×14 흑백으로 변환하며 자료·미리보기·예상에 같은 196개 값을 사용. 배경도 입력됨을 명시. |
| 그림 전체 학습 | 기존 지도 모델은 196칸을 받더라도 연결값이 두 방향으로 제한돼 있었음. 기본 모드를 제한 없는 완전연결 ANN으로 교체. 분류선 지도는 별도의 제한된 원리 실험으로 표시. |
| 지도 좌표 | 특징 탐색의 위치·퍼짐과 학습의 선형 합 계산이 달랐음. 학습 때 고정한 투영 계산으로 통일. 실제 계산에 맞춰 축 이름도 ‘오른쪽−왼쪽 진하기’ 등으로 변경. 새 시험 그림으로 축을 다시 맞추지 않음. |
| 정답을 이용한 지도 | 클래스별 중심으로 축을 정하던 대신 학습 그림만 보는 PCA 사용. 정답 이름을 바꿔도 지도는 그대로임을 테스트. 두 특징이 반드시 좋은 분류를 만든다는 주장을 제거. |
| XOR 선 움직임 | 지정된 두 위치 사이를 단순 보간하던 연출을 실제 역전파 30회 기록으로 교체. 대표 뉴런의 선과 값, 모델의 골 예상, 최종 경계가 같은 모델에서 계산됨. 앞의 분리 가능성 그림은 가능한 배치의 예임을 명시. |
| 학습/시험 점수 | 학습 정답률과 새 그림 직접 시험 결과 분리. 학습 그림의 재시험과 동일 그림 중복 기록을 차단. 모델이 바뀌면 시험 기록 초기화. 높은 예상 점수가 정답을 보장하지 않음을 퀴즈에 반영. |
| 이해 계산 | 한 칸의 진하기 × 연결값 → 다른 칸과 더한 합 → 변환된 뉴런 값 → 출력으로 연결. 같은 한 장만 바꾸며 관찰. 이해 예시 모델은 연습 모델을 덮어쓰지 않음. |
| 클래스/상태 | 숫자·OMR·웹캠·자유 그림의 중복 상태/화면을 ImageLabStore와 ImageWorkspace로 통합. 추가·삭제 시 출력 개수 및 자료 번호를 함께 정리하고 재학습. 사용하지 않는 이전 그림 상태 모듈 제거(Git 이력에 보존). |
| 작은 화면 | 가로 작업면을 세로 화면에서 무리하게 쌓지 않고 작업면 탭으로 전환. 그림과 영상의 정사각형 비율 유지. |
| 텍스트·숫자 | 글자 통계를 의미 이해로 설명하지 않음. 자유 숫자의 새 입력과 내보내기는 정규화된 지도 좌표임을 표시하고 JSON에 변환 범위 포함. |

## 자동 검증

최종 자동 테스트 85개 통과, TypeScript 검사 및 Vite 프로덕션 빌드 통과. 브라우저에서 자료 → 이해 → 100회 학습 → 새 그림 시험 기록, 별도 지도 모드 전환, 선택한 축과 선의 중첩을 확인했다. 1280×720, 768×1024, 390×844 화면을 확인했고, 작은 화면의 도움말 버튼 겹침을 수정했다.

- 입력: 회색값 유지, 196칸 순서, 640×480 영상의 중앙 480×480 잘라내기·거울 방향, 수집/예상 동일 전처리.
- 계산: tanh/sigmoid/ReLU의 입력·출력 연결값과 시작값 전체를 수치 미분과 대조. 실제 학습의 손실 감소와 생성 숫자·OMR 자료 분류 검증.
- 지도: 제한 모드의 실제 그림 예측과 지도 좌표의 배경 예측 일치, 고정 좌표, 클릭 위치, 축 이름, 정답을 사용하지 않는 투영.
- 상태/UI: 사진 복사·맨 앞 추가, 클래스 추가·삭제·재번호화, 테스트 중복 방지, 웹캠 프레임의 자료 전달, 권한 응답 중 페이지를 떠난 경우의 카메라 종료.
- XOR: 모든 애니메이션 프레임을 실제 trainOne 결과와 대조하며 대표 골의 예상이 증가하는지 확인.
- 내보내기: 기존 Scratch 프로젝트·블록·활성화 방식 회귀 테스트 유지.

## 검증의 한계

실제 카메라를 켜서 여러 사람의 가위바위보 인식률을 측정하지는 않았다. 카메라의 연결·수집·종료는 모의 영상 장치로 검증한다. 생성 자료의 높은 학습 정답률은 실제 손글씨·OMR·손 모양에 대한 성능 수치가 아니다. 14×14 흑백, 작은 완전연결 ANN은 교육용이며 사진의 세부 모양·색을 잃고 배경에 영향을 받는다. 모든 크기·확대율·보조기기에서의 접근성을 보장하는 감사도 아니다.

## 개념 대조 자료
