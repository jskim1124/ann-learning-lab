# 직접 조작·계산·연결지도 검토 (2026-09-18)

## 적용한 학습 설계

멀티미디어 학습 연구의 원칙을 UI 설계 기준으로 사용했다. 이 앱의 학습 효과를 실험으로 입증했다는 뜻은 아니다.

- **가까이 제시하기**: 선택 좌표 옆에 그 점의 계산과 예상 표시. 오른쪽 설명과 왼쪽 그래프는 같은 모델의 값을 사용한다.
- **동시에 제시하기**: 입력·더할 값 조절 시 그래프, 은닉 값, 출력 계산을 같은 상태로 갱신한다. 재생은 값 사이의 변화를 보여 준다.
- **단계 나누기와 사전 설명**: 입력 → 곱하기·더하기 → 다음으로 넘기는 숫자 → 출력 비교. 재생만으로 퀴즈를 통과하지 않는다.
- **불필요한 내용 줄이기**: 좌표 변환식은 학생 화면에서 제거. 승부차기는 처음부터 가운데 0, 왼쪽 음수, 오른쪽 양수로 읽는다. 전체 연결선은 펼침 항목에 두되 숫자의 연결지도는 상시 표시한다.
- **연습과 확인**: 계산 객관식, 한 숫자 조절, 선의 일곱 자리 찾기를 사용한다. 오답 선택 시 정답을 자동 공개하지 않는다.

근거: [Mayer·Fiorella, 외재적 처리 줄이기](https://www.cambridge.org/core/books/cambridge-handbook-of-multimedia-learning/principles-for-reducing-extraneous-processing-in-multimedia-learning/F29A19FCD34C542806F736E0661C05F5), [Mayer·Pilegard, 분절화·사전 훈련](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-multimedia-learning/principles-for-managing-essential-processing-in-multimedia-learning-segmenting-pretraining-and-modality-principles/DD24C2F48B9B1277CE59F78276110258).

## 변경 및 계산 검토

1. 승부차기 사진은 실제 ArrowLeft/ArrowRight 키를 처리한다. 클래스 선택은 자동 규칙 또는 직접 지정이며, 규칙과 다른 이름표는 경고 후 사용자가 지정한 값으로 저장한다. 사진의 높이는 모델의 두 번째 입력이 아니다.
2. 새 승부차기 예제는 `h1=max(0,x+y)`, `h2=max(0,-x-y)`, `z=1-h1-h2`. 네 대표 점은 `(±1,±1)`이다. 은닉 하나는 3/4, 두 개는 4/4를 맞힌다. 모든 중간 좌표나 실제 경기를 맞힌다는 주장은 하지 않는다.
3. 선 이동 실험에서는 `(-1,1)`을 고정하고 뉴런 1의 더할 값만 2에서 0으로 줄인다. 넘길 숫자가 2→0, 골 점수가 −1→1로 바뀐다. 이것은 **한 값을 직접 바꾸는 실험**이며 실제 역전파 학습이라고 부르지 않는다. 연습 단계는 기존 실제 학습 알고리즘을 사용한다.
4. 색 뉴런 기준선은 그 뉴런의 합이 0인 자리다. 검은 최종 경계는 **가장 높은 출력 점수의 주인이 바뀌는 곳**이다. 아무 두 출력의 동점선이 모두 최종 경계인 것은 아니다.
5. 선 찾기에서는 같은 위치를 반복해서 누른 것을 중복으로 세지 않는다. 서로 다른 7곳 이후 자동 공개한다. 보라선이 공개되면 다음 출력 소개에서도 유지한다. 별도 '숨은 선 확인' 버튼은 없다.
6. 출력 예제의 뉴런 2는 `max(0,y)`를 C에 더한다. 아래에서는 0, 위에서는 y를 더하므로 경계의 기울기가 달라질 수 있다. 노드 수 자체가 꺾임을 보장하지 않는다. A/C가 가장 높은 동점인 경계의 세 점을 수치 테스트했다.
7. 신호는 계산한 숫자다. 은닉 수와 클래스 수는 독립적이다. 다중 분류는 클래스별 출력 점수를 계산한다. 승부차기 이진 모델은 실제 학습 점수 z 하나와 고정 비교 기준 0을 사용하며 `softmax([0,z])[1]=sigmoid(z)`이다. 숫자 연결지도에는 '답 2개'라고 표시하고 두 별도 학습 출력을 주장하지 않는다.
8. 실제 자료의 정답은 저장한 이름표, 예상은 현재 모델의 계산이다. 새 좌표는 정답 미지정이다. 단, 승부차기는 알려진 수업 규칙의 답을 따로 표시하며 가운데는 제외한다.
9. 연습의 확인점은 학습 자료와 별개다. 드래그·방향키로 확인점을 움직여도 저장된 자료와 모델 연결값을 바꾸지 않는다. 선택된 실제 자료 근처에서는 그 자료와 이름표를 표시한다.
10. 이미지의 **고른 두 특징으로 학습** 모드만 빈 좌표를 직접 탐색한다. 전체 픽셀 모델은 두 좌표만으로 실제 입력 그림을 정할 수 없으므로 자료 그림을 선택해 확인한다. 임의 좌표를 실제 그림으로 꾸며내지 않는다.
11. 학습 그래프의 기본값은 학습 정답률·차이 확대다. 실제 학습 목적의 오차는 여전히 보존한다. 확대 세로축 수치를 표시하며, 학습 기록으로 전역 최적이나 일반화 성공을 판정하지 않는다.
12. 모델 가져가기 항목은 기본적으로 열린다. 예측 전용 내보내기와 카메라 종료·개인정보 처리 동작은 보존한다.

## 검증 범위

- 자동 검사: TypeScript 통과, Vitest 37개 파일·172개 테스트 통과, Vite 프로덕션 빌드 통과.
- 새 회귀 검사: 실제 방향키와 클래스 지정, 6곳/7곳 게이트, 중복 교차점 제외, 다음 장면 선 유지, 구간별 경계 기울기, 드래그 시 자료 보존, 확인점의 실시간 계산, 가져가기 기본 열림.
- 브라우저: 사진 방향키로 `(-0.5,0.5)` 생성; 네 승부차기 계산·퀴즈; 숫자 문제의 모든 이해 단계; 실제 드래그로 보라선과 최종 경계 각각 7곳 찾기; 슬라이더 계산; 100회 실제 학습; 클래스 선택; 연결지도 값 변경; 모델 가져가기 펼침.
- 반응형 점검: 1280×720과 390×844. 기본 작업면과 확장된 추가 설정은 구분한다. 모든 기기·확대율의 무스크롤 동작을 보장한다는 뜻은 아니다.
- 한계: 실제 초·중학생을 대상으로 이해도나 학습 효과를 측정하지 않았다. 이 검토는 수학적 일치성·오개념 방지 문구·상호작용 구현에 대한 검증이다.
