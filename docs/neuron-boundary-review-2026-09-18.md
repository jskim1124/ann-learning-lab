# 뉴런·기준선·최종 경계 설명 개편

## 반영 판단

연결지도를 이해 단계에 추가했다. 처음부터 전체 네트워크를 나열하지 않고,
입력 2개 → 은닉 뉴런 1개 → 출력 A/B만 같은 그래프 아래에 보여 준다.
숫자·OMR·웹캠 이미지 활동이 공통으로 사용하는 ImageFeatureLesson에 적용한다.
자율 문제는 기존대로 이해 단계를 강제하지 않는다.

## 학습 순서

1. 뉴런은 선 자체가 아니라 입력의 수를 계산해서 보내는 작은 계산기다.
2. 가로 0.2 × 1 + 세로 0.2 × 0.5 + 더해주는 값 0 = 합 0.3을 따라간다.
3. 이 예제는 합이 음수면 0, 양수면 그대로 전달한다. 보낸 값은 확률이 아니다.
4. 합이 0인 서로 다른 좌표를 눌러 보라 기준선을 확인한다.
5. 출력 A = 1 − 신호, B = 신호를 비교한다.
6. A/B가 각각 0.5인 점들을 이으면 검은 경계가 된다. 경계 양쪽도 직접 비교한다.
7. 같은 모델·고정된 점에서 한 값만 늘려 선의 이동과 출력값 변화를 확인한다.
8. 출력 C를 추가한 다음 장면도 같은 은닉 계산과 A/B 출력 계산에서 출발한다.

수치들은 원리를 설명하기 위해 정한 작은 예제이며 학습 자료와 분리한다.
한 값만 바꾸는 실험과 실제 자료의 역전파 학습을 혼동하지 않도록 구분한다.
두 종류의 선은 실제 forward 계산에서 산출한다. 보라선은 클래스 경계가 아니며,
다중 분류에서 검은 경계는 모든 출력의 동점이 아니라 1등 출력이 바뀌는 자리다.
은닉 뉴런이 추가된다고 클래스 수나 정답률이 자동으로 증가하지 않는다.

## 그래프

공유 눈금 함수로 원점 중심에 -1, -0.5, 0, 0.5, 1을 표시한다.
픽셀 특징 지도·연습 지도·승부차기·숫자/텍스트 분포에 같은 좌표 변환을 적용했다.
이미지 특징 지도에서 0은 학습 자료의 평균이며 원래 진하기 0이 아니다.
따라서 축 이름에도 평균 0을 명시한다.

## 검증

- 계산 항의 합, ReLU 결과, A/B 출력, 확률과 점수의 구분
- 보라선의 세 좌표는 합 0이지만 출력 동점이 아님
- 검은 경계의 네 좌표는 출력 동점이며 양쪽에서 예상이 바뀜
- 출력 C 추가 전후 기존 은닉 계산과 A/B 출력 점수 유지
- 원점 및 +/-0.5의 캔버스 위치, 숫자 눈금 문자열
- 재생 중 실제 중간값, 일시 정지, 예측 앞 정지, 이전 장면, 단계 이동, 확인 문제
- 전체 단위/통합 테스트, TypeScript 검사, Vite 프로덕션 빌드
- 로컬 브라우저의 계산/그래프/연결지도 및 짧은 가로 화면·세로 화면 검사

학생 대상 사용성 실험은 수행하지 않았다. 수학적 일치와 동작 검증을
학습 효과 자체가 검증된 것으로 주장하지 않는다.

검증 결과: 32개 테스트 파일의 141개 테스트 통과. TypeScript와 프로덕션 빌드 통과.
1280×720, 768×1024, 390×844에서 수정한 장면의 넘침을 점검했다.
작은 화면은 예제·그래프와 설명·확인을 탭으로 전환한다.
검사한 로컬 화면의 브라우저 콘솔 오류는 없었다.
