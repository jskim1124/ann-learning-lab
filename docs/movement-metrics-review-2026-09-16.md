# 선 움직임·출력·학습 지표 검토

## 교육 내용과 계산

- 이해 흐름: 특징 계산 → 분포·선택 → 선 움직임 → 뉴런·출력. 작은 예제와 실제 자료를 구분한다.
- 방향 예제: 고정 입력 (0.2, 0.2), h=max(0, x+0.5y+b), A=1−h, B=h. 다른 값은 그대로 두고 b를 0.1씩 바꾸는 제한된 실험이다. 실제 자료 탭의 역전파와 같은 알고리즘이라고 하지 않는다.
- 세로 0.2에서 A=B인 최종 경계는 h=0.5, 즉 x=0.4−b다. b가 늘면 고정 점의 B 출력은 커지고 최종 경계는 왼쪽으로 이동한다. 보라색 뉴런 기준선(h 변환 전 합=0)과 검은 최종 경계(A=B)를 구분한다.
- 재생은 인접 모델 매개변수를 보간한다. 매 프레임 실제 순전파로 점수·배경 영역·경계를 함께 계산한다. 정지·재개·장면 전환·동작 줄이기를 지원한다. 표시 소수는 반올림 값이다.
- 출력 설명: 입력×연결값+더해주는 값 → 음수면 0 → 클래스별 신호 가중합 → exp 변환 → 합으로 나누어 100%. 변환 규칙은 접어서 설명하며 외우도록 요구하지 않는다.
- 다중 분류 모델은 은닉 1개/2개 모두 클래스 A·B·C에 출력 3개를 만든다. 출력 수와 분류 성능·경계 조각 수는 별개다. 승부차기 기존 이진 모델은 출력 확률 하나와 그 여집합을 쓰므로 모든 신경망이 클래스 수만큼 출력한다는 일반화는 하지 않는다.
- 연습 모델은 은닉 1개로 시작한다. 용량을 늘려 학습 성능을 비교할 수 있다. 기존 성능 회귀 검증은 충분한 뉴런 수를 명시하고 성능 기준을 유지한다.

## 오차와 정답률

- 실제 코드는 교차 엔트로피 오차를 계산한다. 오차는 틀린 답 비율이나 정답률이 아니다. 오차는 낮을수록, 정답률은 높을수록 좋다. 두 값을 매 학습 기록에 저장한다.
- 같은 한 그림을 정답 B로 51%, 99% 예측하면 둘 다 정답률 100%지만 오차는 각각 약 0.673, 0.010이다. 학습 정답률을 새 자료의 성능으로 해석하지 않는다.
- 그래프에서 오차/학습 정답률을 선택하고 세로축 차이를 확대할 수 있다. 축 범위와 확대 여부를 표시한다.
- 학습 횟수-오차 곡선만으로 지역/전역 최적 여부를 판별할 수 없다. 별도 모형 L(x)=(x²−1)²+0.35x+1에서 서로 다른 출발점이 다른 골짜기에 도착하는 애니메이션을 제공한다. 실제 신경망의 지형이나 학습 기록이 아니라고 명시한다.
- 참고: [교차 엔트로피 정의](https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html), [경사 하강법](https://developers.google.com/machine-learning/crash-course/linear-regression/gradient-descent).

## 검증

- TypeScript 검사, 30개 파일의 자동 테스트 128개, Vite 프로덕션 빌드 통과.
- 중간 애니메이션 값, 정지·재개, 단계 전환 중 취소, 실제 출력 비율 계산, 경계 위 점수 일치, 은닉 1개 초기값, 정확도 기록, 그래프 전환/확대 유지, 두 최적점 모형의 오차 감소와 도착점을 검증했다.
- 실제 브라우저: OMR/숫자 이해 단계, 선·점수 동시 변화, 출력 계산, 은닉 1/2개 비교, 연습의 은닉 1개/OMR 출력 5개, 정답률 전환·확대, 최적점 예제 확인.
- 1280×720 및 세로 768×1024, 390×844에서 확인. 좁은 화면은 예제/설명 패널 전환을 유지한다. 화면 크기 변경 시 캔버스를 재계산해 비율이 늘어나는 문제를 수정했다. 모든 화면 크기나 확대율에 대한 보장은 아니다.
- 외부 Scratch 에디터와 실제 웹캠 장비는 이번 변경에서 다시 시험하지 않았으며 기존 자동 회귀 테스트를 유지했다.
