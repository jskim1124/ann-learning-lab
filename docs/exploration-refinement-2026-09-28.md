# 자료 수집 / 이해 탐구 개선

## 화면

- 자료 수집의 원본·14×14 입력은 같은 정사각형 비율을 유지한다. 그림 영역만 남은 높이에 맞추며, 저장 버튼·안내·다음 단계는 별도 고정 행으로 둔다.
- 주요 본문·조작 글자는 기존 기준에서 CSS `1pt`를 뺀다. 페이지 zoom이나 canvas 변환으로 축소하지 않는다.
- 이해 단계의 정답·예상은 점을 클릭할 때만 나타나고 ×로 닫는다. 별도 결과 띠를 없애 그래프 높이를 확보한다.
- 1397×655, 1552×728, 1024×768, 768×1024에서 확인한다. 세로 태블릿은 자료 수집 작업면을 탭으로 전환하고, 이해 화면은 그래프/조작을 위아래에 배치한다. 추가 설명을 펼치거나 클래스를 아주 많이 추가한 경우에는 내용 영역만 스크롤하며 이전/다음 버튼은 유지한다.

## 공통 이해 순서

1. **자료와 특징**: 실제 두 자료를 나란히 비교한다. 그림의 같은 칸을 눌러 진하기×특징 가중값을 확인한다. 두 축 선택/새 특징 만들기/한 축 비교를 같은 장면에서 수행한다. 승부차기는 픽셀 대신 방향을 기록한다.
2. **숫자로 선 만들기**: 실제 입력 → 곱셈 → 뉴런의 합 → ReLU 출력이 연결 지도 위에 놓인다. 슬라이더는 실제 가중치와 편향을 바꾼다. 합이 0인 화면 안의 점을 계산하고 표시한다.
3. **학습 방향**: 선택한 수만 ±0.10 바꾼 전체 자료의 오차를 비교한다. 실제 역전파로 구한 방향으로 한 매개변수만 고칠 수 있다. 변화 재생/별도 기록 버튼은 없앤다.
4. **뉴런 늘리기**: 뉴런 추가/삭제 후 실제 학습을 해 경계와 오차를 비교한다. 출력 수는 클래스 수다. 50회 학습 전후를 하나의 비교·되돌리기 단위로 취급한다.

## 계산 정확성 / 오개념 방지

- 뉴런의 색 선은 `wₓx+wᵧy+b=0`이다. 뉴런 그 자체나 최종 클래스 경계가 아니다. 이 ReLU 실험에서 음수 합은 0, 양수 합은 그대로 보낸다.
- 검은 선은 실제 출력 점수의 최댓값이 다른 클래스로 바뀌는 경계다. 두 특징 모델의 설명이며, 196픽셀 모델 전체를 이 평면이 표현한다고 주장하지 않는다.
- 오차는 평균 교차 엔트로피다. 거리나 정답률이 아니다. 전체 자료와 한 자료의 영향이 다를 수 있다.
- `learningDirection`은 실제 `trainPixelModel`의 동일한 전역 배치 기울기를 사용한다. 한 수의 개선을 보여 주는 실험에는 되짚기(backtracking)를 적용해 너무 큰 이동이 오차를 올리는 일을 막는다. 작은 유한 변화 ±0.10은 현재 위치의 미분과 다를 수 있음을 설명한다.
- 변화율이 0이면 움직인다고 가장하지 않는다. 추가 뉴런의 출력 연결을 0으로 시작하므로 추가만으로 기존 예측은 변하지 않는다. 추가 후 학습으로 연결이 생긴다. 수가 많으면 무조건 더 좋다고 설명하지 않는다.
- 점 좌표는 실제 특징 계산의 평균 중심화/공통 비율을 그대로 쓴다. 클래스 라벨로 위치를 조작하지 않는다. 화면 수는 소수 둘째 자리, 내부 계산은 반올림하지 않는다.
- 모든 계수가 0이면 화면 전체의 합이 0이며 하나의 선이 정해지는 것이 아니다. 퇴화/화면 밖의 선을 가짜로 그리지 않는다.

## 검증

- 실제 기울기와 유한 차분, 한 자료 기울기의 평균, 실제 학습 갱신값 일치 검증.
- 뉴런 추가 시 기존 출력 보존, 같은 칸의 두 그림 계산, 팝업 닫기, 축 변경의 연습 저장소 일치, 원본 그림 저장/초기화 회귀 테스트.
- 전체 255개 테스트 통과 후 최종 UI 보정에 대한 관련 테스트를 재실행한다.
