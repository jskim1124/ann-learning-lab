# 이해 단계 안에서 직접 모델 고치기

## 학습 흐름

별도 연습 모달/진입 버튼을 없애고 공통 이해 과정에서 실제 자료와 같은 실험 모델을 이어서 사용한다. 자율 문제는 기존대로 이해 없이 연습으로 이동한다.

1. 자료 비교: 실제 사례 두 개와 특징 계산, 좌표 분포를 나란히 비교한다.
2. 뉴런 직접 조절: 바꿀 수를 고르면 슬라이더 하나만 나타난다. 실제 가중치 또는 편향, 연결 지도의 계산, 뉴런 기준선이 함께 바뀐다.
3. 오차 줄이기: 줄이기/늘리기를 먼저 예상하고 직접 슬라이더를 조절한다. 고정된 출발점의 오차/기준선과 비교한다. 정해진 정답을 강요하지 않고 악화도 그대로 표시한다. 직접 조작한 뒤 같은 출발점에서 모델의 계산 방향과 비교할 수 있다.
4. 뉴런 늘리기: 새 뉴런을 추가한 뒤 특정 클래스에 보내는 값의 연결 비율을 조절한다. 클래스별 출력 수는 그대로이며, 고른 출력에 들어가는 모든 뉴런의 실제 곱과 합을 연결 지도에서 확인한다. 자동 학습도 같은 모델에 적용한다.

상단 장면 이동은 자유롭고 실험 모델은 유지된다. 자료나 특징을 바꾸면 좌표 체계가 달라지므로 실험 모델은 초기화한다. 이해의 두 입력 ReLU 모델과 그림 전체를 학습하는 연습 모델은 구분한다.

## 계산 및 상태 불변식

- 색 선은 은닉 뉴런 그 자체가 아니라 가중합이 0인 기준선이다. 검은 선은 최종 최대 점수 클래스가 바뀌는 경계이다.
- 한 슬라이더는 한 매개변수만 바꾼다. 비교 실험 동안 원자료와 다른 가중치는 고정된다.
- 모델 비교는 학생 조작 후 위치가 아닌 저장한 출발점에서 시작한다. 실제 전체 자료의 평균 교차 엔트로피 변화율을 사용한다.
- 변화율 0이면 가짜 이동을 만들지 않는다. 작아서 소수 둘째 자리 표시가 같을 때는 이를 설명한다.
- 오차는 정답률 또는 점과 선 사이 거리와 다르다. 가짜 개선이나 미리 만든 이동 애니메이션을 쓰지 않는다.
- 추가한 뉴런의 출력 연결은 0이다. 추가만으로 예측이 달라지지 않으며 연결을 조절하거나 학습해야 영향을 준다.
- 출력 연결의 음수는 음수가 아닌 은닉 값의 기여를 빼는 의미이다. 출력 점수는 확률이 아니며 확률은 기존 예측 팝업에서 따로 확인한다.
- 모델 및 지도에는 반올림 전 값을 사용하고 표시만 소수 둘째 자리로 고정한다.

## 검증

실제 DOM 경로에서 연습의 별도 진입점 제거, 이해 재방문 시 값 유지, 자율 문제 바로 연습을 회귀 테스트한다. 직접 조작 전 예상, 실험 출발점 고정, 다시 예상, 한 매개변수 학습 비교, 0 변화율, 출력 연결 조절 및 장면 간 모델 보존을 테스트한다. 브라우저에서 1397×655, 1024×768, 768×1024 배치와 조작을 확인한다.
