# Neural Lab

학습자가 작은 인공신경망을 직접 구성하고, 데이터가 가중치와 판단 경계로 바뀌는 과정을 관찰하는 브라우저 기반 학습환경입니다. 결과 예측만 보여주는 도구와 달리 모델의 구축·학습·검증 과정을 하나의 활동 흐름으로 연결합니다.

## 학습 흐름

1. XOR·AND 활동 데이터를 선택하거나 두 범주의 점을 직접 입력합니다.
2. 은닉 뉴런 수, 활성화 함수, 학습률을 설정합니다.
3. 실제 배치 경사하강법을 반복하며 판단 영역과 손실 변화를 관찰합니다.
4. 은닉 뉴런별 활성화 경계와 실제 가중치 네트워크를 확인합니다.
5. 임의의 입력값이 각 뉴런을 거쳐 예측으로 바뀌는 계산을 검증합니다.
6. 조건별 결과를 표에 기록해 학습자의 선택이 성능에 미친 영향을 비교합니다.
7. 모델 JSON 또는 TurboWarp·사용자 정의 Scratch 환경용 확장 파일을 내보냅니다.

## 주요 설계 원칙

- 같은 초기값을 사용해 구조 변화의 효과를 비교할 수 있습니다.
- 은닉 뉴런의 경계와 최종 분류 경계를 구분해 표시합니다.
- 손실, 정확도, 가중치, 활성화값은 실제 학습 중인 모델에서 계산됩니다.
- 실험 결과는 브라우저에만 저장되며 외부 서버로 전송되지 않습니다.

## 프로젝트 구조

```text
dist/
├── index.html          # 학습환경 화면 구조
└── assets/
    ├── styles.css      # 디자인·반응형 레이아웃
    └── app.js          # 신경망 학습·시각화·내보내기
vercel.json             # Vercel 정적 배포 설정
```

별도의 빌드 과정이나 서버가 필요하지 않습니다. Vercel의 배포 디렉터리는 `dist`입니다.
