# Neural Lab

중학생이 자료를 모으고 실제 신경망을 학습·시험하는 브라우저 실험실입니다. 단계별 화면으로 진행하며, 사진은 서버에 보내지 않습니다.

## 실행·검증

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

Vercel Git 연동은 `main`의 Vite 정적 빌드 결과 `dist`를 배포합니다.

## 공통 구조

- `core/imageInput.ts`: 웹캠·그리기 공통 전처리. 중앙 정사각형 → 14×14 흑백 진하기 196개. 미리보기·수집·예상에 같은 값을 사용합니다.
- `state/imageLabStore.ts`: 숫자·OMR·웹캠·자유 그림의 단일 자료/클래스/학습 상태.
- `ui/imageWorkspace.ts`, `.css`: 클래스별 자료 → 학습 → 새 그림 시험의 공통 UI. 클래스 2~10개, 은닉 뉴런 1~16개. 작은 화면은 작업면 탭을 사용합니다.
- `core/pixelNetwork.ts`: 모든 픽셀의 연결값을 학습하는 완전연결 ANN, 역전파, softmax, 교차 엔트로피. 기본값은 그림 전체 학습입니다.
- `core/pixelProjection.ts`: 선택적인 두 기준 지도 실험. 기본 모델과 다르게 입력 연결값을 두 방향으로 제한합니다. 지도에서 점과 배경이 같은 예상을 내는 것은 **이 제한된 모드에만** 해당합니다. PCA는 학습 그림으로만 계산하며 정답 클래스를 사용하지 않습니다.
- `core/neuralNetwork.ts`, `state/labStore.ts`: 두 입력의 승부차기 XOR 및 기존 모델 호환.
- `state/featureLabStore.ts`: 자유 숫자·텍스트 자료의 두 특징 실험. 텍스트의 의미를 이해하는 모델이 아니라 글자 수 등 통계의 분류입니다.
- `visualization/xorLesson.ts`: 앞 세 장면은 분리 가능성의 예, 마지막 장면은 실제 역전파로 계산한 30회 학습 기록입니다.
- `export/`: Scratch 표준 블록 프로젝트(.sb3), 모델 JSON, 기존 TurboWarp 확장.

## 수업에서 구별할 것

1. 그림 전체 ANN의 196차원 판단을 두 축의 경계선으로 정확히 표현할 수는 없습니다. 기본 모드에서는 그림별 예상·은닉 뉴런·연결 지도를 보여 줍니다. 분류선은 별도의 두 기준 실험에서 살펴봅니다.
2. 학습 정답률은 이미 모은 자료의 성적입니다. 활용 단계에서 학습에 넣지 않은 새 그림을 별도로 기록합니다. 이 소규모 시험이 일반적인 인식 성능을 보장하지는 않습니다.
3. 숫자·OMR의 시작 자료는 생성한 연습용 그림입니다. 웹캠은 실제 촬영 자료로 시작하며, 작은 14×14 모델은 배경·조명·위치에 민감합니다. 사전학습된 Teachable Machine 모델과 같은 정확도를 주장하지 않습니다.
4. 뉴런의 합과 변환한 중간값, 뉴런 기준선과 최종 판단 경계를 구분합니다. 뉴런 수를 늘린다고 항상 성능이 좋아지지는 않습니다.

## Scratch

.sb3는 Scratch의 ‘컴퓨터에서 불러오기’로 엽니다. 이미지 모델은 ‘그림 밝기’ 목록의 196개 진하기(흰색 0, 검정 1)로 예측합니다. 기본 Scratch 블록이 웹캠 전처리를 자동으로 수행하는 것은 아닙니다. 두 특징 모델에는 원래 단위가 아닌 지도 좌표를 입력합니다.

JavaScript 확장은 TurboWarp 등의 사용자 확장 환경용이며 공식 Scratch의 .sb3와 구별합니다.
