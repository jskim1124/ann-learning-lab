# Neural Lab

데이터 생성 → 신경망 구성 → 실제 학습 → 내부 계산 관찰 → 검증·내보내기를 한 화면에서 수행하는 교육용 웹 실험실입니다. 모든 판단 영역, 은닉 뉴런 활성화, 가중치, 손실과 입력 계산식은 브라우저에서 학습 중인 하나의 모델 상태에서 계산됩니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

## 검증과 배포 빌드

```bash
pnpm test
pnpm build
```

Vercel은 `main` 브랜치의 Vite 정적 빌드 결과인 `dist`를 배포합니다.

## 코드 구조

```text
src/
├── core/             # 초기화, 순전파·역전파, 손실, 모델 스키마 검증
├── data/             # XOR·AND 데이터와 데이터 조작 규칙
├── export/           # model-v2 JSON과 TurboWarp 확장 생성
├── state/            # 실험 상태, 초기화 규칙, 기록 저장
├── visualization/    # 판단 영역, 뉴런 경계, 네트워크, 손실 그래프
├── main.ts           # 화면 연결과 사용자 상호작용
└── styles.css        # Teachable Machine 계열의 작업면 디자인과 반응형 규칙
```

## 교육적 비교 기준

기본 XOR 데이터, 고정 시드, `tanh`, 학습률 `0.08`, 1,000 epoch에서 은닉 뉴런 1개보다 2개가 더 높은 성능을 내고 2개 모델이 12개 점을 모두 분류하는지 자동 테스트합니다. 이 대비가 깨지면 테스트가 실패합니다.

## Scratch 사용 제한

내보낸 JavaScript는 TurboWarp 또는 사용자 정의 확장을 허용하는 Scratch 계열 환경에서 비샌드박스 사용자 확장으로 불러옵니다. 공식 Scratch 웹사이트는 임의의 사용자 확장 파일을 직접 불러오는 기능이 제한되므로 지원 대상으로 안내하지 않습니다. 확장은 내보낸 가중치로 추론만 수행하며 외부 서버에 데이터를 전송하지 않습니다.
