활동 방법
한 화면씩 천천히 진행하세요
  1. 학교생활 문제를 하나 고릅니다.문제 속 두 조건과 두 결과를 확인합니다.
  2. 점으로 나타낸 사례를 살펴봅니다.직선 하나로 나눌 수 있을지 먼저 예상합니다.
  3. 모델을 여러 번 연습시킵니다.틀린 정도가 줄고 맞힌 비율이 올라가는지 봅니다.
  4. 네 장면의 그래프 문제를 풉니다.여러 기준선이 합쳐져 마지막 선이 되는 과정을 확인합니다.
  5. 새 값을 넣거나 Scratch로 가져갑니다.
